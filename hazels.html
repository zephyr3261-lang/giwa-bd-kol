第二部分 · 运营模式

2.1 一句话概括

Hazels 不是"卖图片"，而是把 NFT 做成一张会员卡，套在一门"创作者活动服务"的生意上。

它对外销售的三样东西： 1. 一张身份凭证（NFT） 2. 一个创作者接任务的平台（Studio / Pulse） 3. 一组只给持币人的稀缺机会（Drops：合作方白单）

2.2 四层结构（官方文档口径）

层 作用 谁付钱
Attention Layer（Pulse） 项目方在此发布创作者任务，按贡献结算 项目方付服务费
Hazels NFT 持久的文化身份与会员资格 购买者
Azura SI 辅助创作者理解任务、辅助团队审核的分析工具（原型阶段） 订阅/计量（规划中）
Drops 把合作方 NFT 库存转为"只给质押者"的奖励池 合作方付服务费
IP Collectibles 实体周边与授权（计划把净利 10% 分给质押者，目标 2027 Q2） 消费者

结构性原则（官方明确写出）：活动预算不等于平台收入；合作方 NFT 池不占自家供给；社交评分不等于贡献分。 这三条边界把"别人给的钱"和"自己的资产"分开记账，是它敢长期做承诺的基础。

2.3 白单是怎么发的：不是抢，是挣

核心机制是 GTD Race：

  • 创作者用 X 账号登录 Studio、绑定钱包，参与活动
  • 平台按"贡献"（内容产出、带人、任务完成质量）排名
  • 排名前 500 锁 guarantee（一排名对应一个名额）
  • 另有 Social Score ≥ 50 的准入门槛，用于过滤空号与批量账号
  • 规则在铸造前公示，铸造后不改

经济含义：白单是平台发放的"非现金激励"。参与者用劳动换确定性，平台用资格换内容与传播，双方不产生现金支出。这使它在预算有限时仍能制造内容密度。

2.4 分发：把白单当广告费，批量外包给长尾社区

做法： 1. 与 45 个中小社区/DAO 逐一开抽奖（Tessera 平台承载） 2. 提供统一模板，合作方直接发布 3. 每场发放 8–50 个白单不等，平均每场 44 人报名

模板结构固定（合作方页面可查原文，含未替换的 [PARTNER NAME] 占位符）：

GIVEAWAY TEMPLATE: HAZELS × [PARTNER NAME]
1) 合作声明 + 名额数量
2) 项目一句话定位
3) 参数：供给 / GTD 价 / WL 价
4) 时间表：GTD 窗口 / WL 窗口 / 公开窗口 + mint 平台

为什么有效：进入漏斗的都是完成了任务、加了 Discord、留了地址的人，而不是浏览者。45 个社区 × 44 人 ≈ 3,200 人次合格参与，最终成交 1,337，转化约 42%。

2.6 收入模型

业务 收入来源 可持续性判断标准（官方口径）

明确不发代币、不承诺收益，只承诺使用权。文档原文 "no token promise and no yield"。这既是合规取向，也避免了"发币即终点"的预期管理问题。

2.7 叙事运营

抽样 31 条帖文的结构：

  • 世界观/角色内容 ≈ 35%
  • 结构化活动公告（→ Duration / Reward / Eligibility 固定格式）≈ 35%
  • meme / 玩梗 ≈ 20%
  • 互动型抽奖（猜谜、答对抽奖）≈ 10%

配套动作：公开招 Discord 管理员（释放扩张信号）、反复强调"官方从不主动私信、只在唯一页面 mint"（降低钓鱼风险与信任成本）。

第三部分 · 特别值得学的点

以下 7 条是本次研究认为真正的差异点，按"现象 → 机制 → 为什么有效 → 可迁移做法"组织。

学习点 1：把一次失败的 mint 处理成信任资产

现象：9/30 首铸，283 人排队只有 81 人成功，官方当天取消、全额退款、换平台、降价 4 倍，10/14 重启并售罄。

机制：公开复盘（写明排队人数与成功人数）→ 立即退款 → 更换基础设施（自建站 → OpenSea）→ 重定价格与节奏。

为什么有效：mint 事故本身不可怕，可怕的是含糊处理。它把"我们错了"变成可核验的动作序列：数字公开、钱退掉、平台换掉、时间重排。对社区而言，这比一次顺利的 mint 更能证明团队扛事。

可迁移：预设事故预案。写清三件事——出问题多久内公告、退款路径、重启条件。真实事故发生时直接执行，不临场决策。

学习点 2：供给"事后锁死"而非"事前承诺"

现象：对外一直说 5,555，实际成交 1,337，之后把链上供给永久锁在 1,337。

机制：mint 结束按实际铸造量定终局，未售出部分不保留、不增发。

为什么有效：铸造前砍供给显得"卖不动"，铸造后锁死则显得"卖完了就收"。同一个数字，叙事方向完全相反。同时也消除了"团队会不会偷偷增发"的疑虑——合约层面就没有更多额度。

可迁移：不在 mint 前把供给数字改小；改为铸造结束后按成交数锁死，并公开说明"不会再有新增"。

学习点 3：把白单做成"赚来的资格"，而不是"抢到的折扣"

现象：GTD Race 前 500 名锁名额；Studio 累积 2 万+ 创作者；Social Score ≥ 50 门槛。

机制：资格 = 贡献排名，而非时间先后或付费。

为什么有效： - 对平台：白单是零现金成本，却能批量换取内容与传播 - 对参与者：确定性来自"我做到了"，而非"我手快"，留存更强 - 对结果：参与者自发生产内容，形成不需要预算的内容供给

可迁移：把"白单发放"重写为"排行榜发放"。哪怕起步只用表格，只要规则公开、周期固定（2–4 周）、名次与名额对齐，就能跑起来。

学习点 4：分发靠广度，不靠深度

现象：45 个社区、80 场抽奖、平均 44 人/场。

机制：把一次预算拆成 30–50 份，每份 = 10–30 个白单 + 一份模板 + 一个报名入口。

为什么有效：头部长尾的差别不在曝光，而在合格参与。大 KOL 带来浏览，小社区带来留了钱包地址的人。而 NFT 铸造只需要后者。

可迁移：设"场次"为管理单位——每场 30–100 人报名、10–30 个名额、统一模板、结果可核验。40 场就是 1,200–4,000 人次。

学习点 5：软质押是"摩擦设计"，不是"技术炫技"

现象：签名即质押，NFT 不离钱包、无 gas、无锁仓；但挂单即质押失效、sYOURAI 清零。结果挂单率仅 6.4%。

机制：参与成本降到接近零（签名），退出成本抬到有心理损失（记录清零）。

为什么有效：传统质押要转账、要锁仓、要 gas，参与者少；软质押几乎人人可参与。而"挂单即清零"把抛售和行为记录绑定，等于给持有加了一层软约束——卖是允许的，但要付心理代价。

可迁移：任何"持有型权益"都可以用这个结构：零门槛进入 + 时间累积 + 行为即失效。不需要真锁仓。

学习点 6：用别人的白单养自己的持有者

现象：Drops 里持续给质押者发"Clover 25 个免费 mint 名额""Karmafuckers 50 个 GTD"，全部来自合作方。

机制：项目方向其他项目争取库存，作为自身持有者的专属权益；合作方获得曝光与精准人群。

为什么有效：自身持续产出权益的成本极高，而"撮合别的项目的库存"成本接近零。持币人每天都能看到"又有一个只给我们的机会"，地板就有支撑。

可迁移：把"权益采购"当成常规运营动作，每周争取 1–2 个外部名额池，而不是每次自己发东西。

学习点 7：文档即产品

现象：hazels.io/docs 涵盖收藏、质押、权益矩阵、商业模型、术语表、FAQ，甚至可以查到"记录模型应该有哪些字段"。

机制：把规则、边界、口径全部写死并公开，包括"活动预算不是平台收入""社交分不是贡献分"这类容易被误解的边界。

为什么有效： - 降低客服成本（80% 的重复问题在文档里） - 降低信任成本（规则在钱进来之前定好，事后不能改） - 提高专业度（能写出术语表的项目，通常内部真的在按规则跑）

可迁移：任何要收钱的项目，先写一页 FAQ + 一页规则，再开始宣传。文档里必须包含"我们不承诺什么"。

第四部分 · 方法论收敛

上述 7 点可压缩为一个五段结构（S-Q-E-D-R），用于任何供给 500–5,000 的中小型 NFT 项目：

层 问题 动作 参数参考
S 供给 怎么保证售完 按确定性需求定量，成交后链上锁死 供给 ≤ 白单池 × 0.4
Q 定价 白单凭什么值钱 阶梯轮次 + 小价差 + 早轮限购 价差 ≤ 25%；GTD 限 1–2
E 资格 没钱投营销怎么办 榜单发放，规则前置公开 周期 2–4 周，前 N 名锁名额
D 分发 怎么低成本铺开 30–50 个长尾社区，统一模板 每场 10–30 名额，30–100 人报名
R 留存 怎么守住地板 延迟 Reveal + 软质押 + 外部白单注入 Reveal 7–10 天后；每周 1–2 个外部池

三条杠杆：稀缺（供给收缩与早轮限购）、身份（资格而非折扣）、外部（他人社区发声、他人白单供给）。

第五部分 · 局限、风险与待确认

5.1 数据局限

  • 报名人次仅统计页面可见数值的 72 场，实际总量高于 3,193
  • X 侧发帖账号为关键词检索结果，是下限而非全量
  • 转化率 42% 为总量估算，无平台级归因
  • 单帖浏览中位约 8,400 来自 14 条样本
  • 创作者数量（5,000 → 10,000 → 20,000+）来自官方推文与第三方报道，未独立核验

5.2 模型失效条件

条件 后果
白单池靠多号刷出，无真实购买力 报名多、成交少，售罄失败
长尾社区质量差（纯撸毛） 参与人次虚高，转化极低
无持续权益生产能力（拿不到外部白单） 质押空转，地板回落
自身内容供给能力弱 Reveal 期间无内容可发，热度断层
过度依赖单一平台（抽奖平台/交易平台） 规则或政策变更即失速

5.3 待确认

  • 团队规模与实际交付能力（公开信息仅见创始人）
  • 8 条角色线的版权与后续 IP 变现路径
  • Drops 的合作方付费规模（判断 Attention Layer 是否为真实收入）
  • 20,000+ 创作者中"有实际提交"的比例
